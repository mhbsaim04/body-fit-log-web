# Project name:
A website of workout library and daily training planner built with Next.js App Router.

# Short description:
FitLog lets you browse a 12-workout library, open a dedicated workout detail page. It also add lifts to today's plan, save workouts for later, mark planned workouts as done, and keep the plan state after reloads with localStorage.

# Technologies used:
1. Next.js 16 App Router
2. React 19
3. TypeScript
4. Tailwind CSS v4
5. Lucide React icons
6. React Hot Toast
7. Remote workout API with fallback endpoint
8. localStorage persistence

# 5 key features of the project:
1. Responsive workout library with a Figma-inspired dark/lime visual system.
2. Today's Plan with a maximum of five lifts.
3. LocalStorage persistence across browser reloads.
4. Duration, calories, and rating sort controls.
5. Mark as Done and Remove actions with toast feedback.
